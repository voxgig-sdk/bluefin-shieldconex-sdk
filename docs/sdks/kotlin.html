Set up the client

This setup fragment reads credentials from the environment. Use the API operation reference to supply input for each call.

import voxgig.bluefinshieldconexsdk.core.BluefinShieldconexSDK

val client = BluefinShieldconexSDK(mutableMapOf<String, Any?>(
    "apikey" to System.getenv("BLUEFIN_SHIELDCONEX_APIKEY"),
))

Client defaults

{
  "base": "https://secure-cert.shieldconex.com/api",
  "auth": {
    "prefix": "Basic",
    "basic": true
  },
  "headers": {
    "content-type": "application/json"
  },
  "entity": {
    "detokenize": {},
    "tokenize": {},
    "tokenize_batch": {},
    "tokenize_read": {},
    "validate": {}
  }
}
